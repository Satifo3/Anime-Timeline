# ANIME TIMELINE — Prototype

ブラウザだけで動く、アニメ作品を放送開始順に並べるミニゲームの試作版。

## 起動
`index.html` を開くだけです。GitHub Pagesにもそのまま配置できます。

## 現在
- 32作品の仮データ
- 10問 / 20問
- 放送開始日の位置当て
- スコア / リザルト
- PC / スマホ対応

## 正式版予定
1994–1999: 80 / 2000–2009: 130 / 2010–2019: 80 / 2020–2026: 15 = 305作品。
TV / OVA・OAD / 劇場版を収録予定。

※この試作データはUI・ゲームロジック確認用。正式版では各作品の一次・信頼できる二次情報源を照合して確定する。

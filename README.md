# ANIME TIMELINE — Prototype v0.9

参考画像のUI構成に寄せて、プログラムの画面レイアウトを全面改修。

## 縦向き
- 上部に小型アイコン＋アニメタイムラインロゴ
- 問題 / スコア / 正解率を3分割表示
- 問題カードを映画フィルム風パネル化
- その下にタイムラインを配置
- 画面下部に終了 / 10問 / 20問 / レコード操作

## 横向き
- 上部にロゴ、問題数、スコア、正解率
- 左：現在の問題
- 右：横幅を活かした広いタイムライン
- 下：BEST SCORE / 10問 / 20問 / レコード
- 左側を巨大アイコンが占領する構成は廃止

## 共通
- 160作品
- BEST SCORE
- 上位10レコード
- 正解率表示
- iPhone Safe Area
- GitHub Pages
- 全ファイル同階層のフラット構成
